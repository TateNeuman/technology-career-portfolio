# Project Retrospective

**Project:** Technology & Career Portfolio  
**Project Manager:** Tate Neuman  
**Class:** Fundamentals of Computing Applications

## 1. Things That Went Well

One of the key successes that I had in this project was being able to use my knowledge from this class to make an entire website. I gained more confidence in using HTML, CSS, Git, and GitHub. Making a project scope prior to starting the development process helped me know what I had to do and kept me focused on the requirements.

Another success I had was getting better at organizing the project files and documents. By using a separate docs folder, the repository became more organized. I received feedback from other students about making my scope statement clearer, particularly the description of the project and the documents.

## 2. What Went Wrong?

One of the issues that I faced during this process was that I found it difficult to publish the website through GitHub Pages because when I uploaded my files, the website showed me a 404 error. This required me to change the repository settings for GitHub Pages to publish my website from the main branch and root folder.

The other issue that I faced was the difficulty in keeping a record of all the deliverables. Because there were many HTML files, CSS files, and three planning files in the final project, it was easy to miss any small deliverable.

## 3. What Would I Do Differently?

In my next project, I would plan out a checklist and schedule before starting development work on the project. I would divide up the project into smaller components and check off each component as I finish it. I would also run tests for GitHub Pages at an earlier stage rather than leaving it to when I have developed the whole website.

I would continue to use feedback loops in order to pinpoint any issues and improve my work. Chapter 7 stresses the importance of learning from past projects, and this particular project helped me appreciate that point of view.

This project helped me gain more confidence working on my own small technology project.
