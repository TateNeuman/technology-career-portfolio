# Project Scope Statement

## Project Name

Technology & Career Portfolio

## Project Purpose

The purpose of this project is to create a professional website that presents my education, technology interests, developing skills, projects, and career goals. The website will allow me to practice web development and project management while creating a portfolio that demonstrates my experience and interests in the technology field.

## Description

The project will consist of a two-page technology and career portfolio website. The homepage will introduce me and provide information about my education, technology interests, skills, projects, and career goals. The About page will provide additional information about my background and interests.

The website will be created using HTML and CSS and will use a single external stylesheet to maintain a consistent design. All project files and planning documents will be stored in a public GitHub repository. The repository will also contain a professional README file and a docs folder containing the required project documentation.

## Desired Results

The completed project will:

- Include a functional `index.html` homepage.
- Include a functional `about.html` page.
- Include navigation between both pages.
- Use one external `style.css` file for consistent styling.
- Present information about my education, technology interests, skills, projects, and career goals.
- Include a professional `README.md` explaining the project and linking to the live website and documentation.
- Include a `docs/` folder containing:
  - `scope.md`: The revised Project Scope Statement incorporating peer feedback.
  - `plan.md`: A project plan containing a risk analysis using the TAME framework and a Work Breakdown Structure.
  - `retrospective.md`: A reflection discussing what went well, what went wrong, and what I would do differently.
- Be organized in a single public GitHub repository.
- Have a working website published through GitHub Pages.

## Exclusions

The project will not include:

- JavaScript or other advanced programming languages.
- A database or user account system.
- E-commerce or payment features.
- A contact form that collects or stores user information.
- More than the two required website pages.
- Advanced web frameworks or libraries.

These features are outside the scope because the project is focused on creating a simple two-page website using the skills covered in the course.

## Feedback Loops

Feedback will primarily come from my instructor and classmates. Peer feedback from Assignment 04 will be used to revise the Project Scope Statement before it is included in the final project. I will also review the website throughout development to check the content, navigation, appearance, and project requirements. Feedback and revisions will be addressed before the final GitHub repository is submitted.

## People Resources

I will serve as the project manager and developer for the project. I will be responsible for planning, writing the documentation, creating the HTML and CSS, testing the website, and maintaining the GitHub repository. My instructor and classmates will provide feedback that can help identify areas that need improvement.

## Priorities

The project constraints will be prioritized as follows:

1. Quality
2. Time
3. Budget

Quality is the highest priority because the website and repository need to meet the project requirements and function correctly. Time is the second priority because all parts of the project must be completed by the course deadline. Budget is the third priority because the project will use free tools and resources.

## Time

The project will be completed by the final Project 03 deadline established by the course schedule. Work will be divided into planning, website development, testing, revision, documentation, and final submission.

## Quality

The finished website will contain two working HTML pages with clear navigation and consistent styling from one external CSS file. The HTML and CSS files will be organized correctly, and the content will be readable and professional. The GitHub repository will contain all required files and documentation.

## Budget

The expected budget is $0. The project will use free tools and resources, including GitHub, GitHub Pages, HTML, CSS, and the software already available for the course.

## Acceptance Criteria

The project will be considered complete when:

- The public GitHub repository contains all required files.
- `index.html` and `about.html` are complete and linked together.
- `style.css` provides consistent styling for both pages.
- `README.md` clearly explains the project and provides links to the live website and documentation folder.
- The `docs/` folder contains the revised Project Scope Statement (`scope.md`), project plan with TAME risk analysis and Work Breakdown Structure (`plan.md`), and project retrospective (`retrospective.md`).
- The website is published through GitHub Pages and functions correctly.
- The final project meets all Project 03 requirements.
- The GitHub repository link is ready to be submitted to the instructor.
