# Technology & Career Portfolio

## Project Overview

This project is a two-page personal portfolio website created to showcase my education, technology interests, developing skills, projects, and career goals.

The website was developed as part of Project 03 for my Fundamentals of Computing Applications course. It demonstrates my understanding of basic web development, project management, documentation, and version control.

## Website Features

- A homepage introducing my education and career interests.
- An About page providing additional background information.
- Navigation between both website pages.
- Consistent styling using one external CSS file.
- A simple and professional design.

## Technologies Used

- HTML5
- CSS3
- Git and GitHub
- GitHub Pages
